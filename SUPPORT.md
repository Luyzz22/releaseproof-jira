# Support — ReleaseProof

ReleaseProof is a Jira Cloud application. Start with [releaseproof.de](https://releaseproof.de/) for product information and the [Atlassian Marketplace listing](https://marketplace.atlassian.com/apps/4034622287/releaseproof) for the installed application.

## Public GitHub issues

Public issues are suitable for non-sensitive, reproducible defects and documentation suggestions. Include the relevant ReleaseProof version, synthetic Jira project configuration, expected/observed behaviour, and sanitized steps. Never include live Jira issue descriptions, customer identifiers, access tokens, personal data or confidential release details.

## Security issues

Use the confidential channel described in [SECURITY.md](SECURITY.md). Do **not** disclose security findings in public issues.

## Support expectations

Support terms, if any, are governed by the relevant agreement or Marketplace listing. This repository does not publish a response-time guarantee or a production-availability SLA.

## Product boundaries

ReleaseProof evaluates configured readiness rules. It does not modify Jira work items, replace release management approval, execute production deployments, or claim audit certification.
